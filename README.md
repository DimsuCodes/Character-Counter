# Character Counter

A React + TypeScript + Tailwind app for Per Scholas Lab 2. Users type text and see live stats.

## How to run
npm install
npm run dev

## Components
- **TextInput**: I didn't completely finish this due to time but the idea of the text input is to have a space for the
users to be able to input their text in order for it to be counted by the Character Counter.
- **StatsDisplay**: This portion is also incomplete but the idea of the Stats Display is to display the time it takes for
user to type and input their text inside of the TextInput.
- **CharacterCounter**: The idea of the character counter is to take the information from the text input and log the character count inside of the textbox a.k.a the TextInput.
